# Contributing

OpenA8DJ is an independent MIT-licensed compatibility project. Contributions
are welcome when they preserve that boundary.

By contributing, you certify that your contribution:

- is your original work or is based on material that can be contributed under
  the MIT License;
- does not copy Native Instruments code, binaries, firmware, installers, logos,
  screenshots, or other proprietary material;
- does not copy third-party implementation code under incompatible license
  terms;
- does not include confidential, NDA, partner-portal, or private SDK material;
- uses third-party product names only for factual compatibility references.

Use public facts, live hardware testing, and original implementation work. If a
change depends on information from another project, document the source and keep
the implementation independent.

Before opening a pull request, read
[docs/reference/legal.md](docs/reference/legal.md) and make sure the
release/publication policy still holds.
