# Windows Installation Guide: Unsigned Development Package

This page is kept as a compatibility link for older handoffs and package
references. Use the current [Windows installation guide](WINDOWS.md), which
covers download, test-signing, verification, and uninstall in one place.

The package is experimental because the driver is not Microsoft-signed for
production distribution. Windows test-signing mode is required during
installation. No separate recovery procedure is needed beyond the normal
Windows restart requested by the installer.

For implementation and validation information, see
[Windows technical details](WINDOWS_DETAILS.md).
