# Project State

This directory preserves raw project state for maintainers and future agents.
It is intentionally more detailed and noisier than the public documentation.

Use the public documentation first:

- [Documentation index](../README.md)
- [Architecture](../project/architecture.md)
- [Testing and validation](../project/validation/testing-and-validation.md)

## What Belongs Here

- handoffs between agents or maintainers;
- raw test evidence;
- rejected experiments;
- date-stamped runbooks;
- signing and notarization state;
- branch-state notes;
- internal investigation notes.

## What Does Not Belong Here

- normal install instructions;
- consumer troubleshooting;
- public release notes;
- architecture explanations intended for new contributors.

Those belong in `docs/user`, `docs/project`, or `docs/reference`.
