OpenA8DJ 0.5.2 Lifecycle Preview
================================

This preview contains lifecycle stability changes for limited testing. It is
not the recommended stable download; OpenA8DJ 0.5.1 remains the stable release.
The HAL and tools use ad-hoc code signatures. The PKG and DMG are unsigned,
and no artifact is Apple-notarized.

Install
-------

1. Verify the DMG with the published SHA-256 checksum.
2. Open the DMG and double-click OpenA8DJ-0.5.2.pkg.
3. If macOS blocks the installer, use Finder's Control-click > Open flow or
   System Settings > Privacy & Security > Open Anyway after verifying the
   checksum. Do not disable Gatekeeper.
4. Follow the Installer steps, then connect or reconnect the Audio 8 DJ.
5. Reopen Traktor or any audio application that was already running.

Check The Installation
----------------------

1. Open Audio MIDI Setup.
2. Select Open Audio 8 DJ and confirm 8 inputs and 8 outputs.
3. Select Open Audio 8 DJ in your audio application.
